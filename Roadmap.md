# TypeScript Full Stack Roadmap

| Part   | Title                                     | Summary                                                                                                                                                        | Study time |
| ------ | ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| **0**  | Foundation & Setup                        | What TS is, how compilation works, installing, running code, and every important `tsconfig.json` option explained.                                             | 3-4 hrs    |
| **1**  | Basic Types                               | Annotations vs inference, primitives, `any`/`unknown`/`never`, arrays, tuples, enums, literals, assertions, `as const`, `satisfies`, unions and intersections. | 5-6 hrs    |
| **2**  | Functions                                 | Typing parameters and returns, overloads, `this`, callbacks, higher-order functions, async functions.                                                          | 4-5 hrs    |
| **3**  | Objects, Interfaces & Narrowing           | `interface` vs `type`, index signatures, structural typing, discriminated unions, type guards, exhaustive checks.                                              | 6-7 hrs    |
| **4**  | Generics                                  | Generic functions, types and classes, constraints, `keyof`/`typeof`, API wrapper and repository patterns.                                                      | 5-6 hrs    |
| **5**  | Utility & Advanced Types                  | Built-in utility types, mapped and conditional types, `infer`, template literals, and how to decode complex types.                                             | 6-8 hrs    |
| **6**  | Classes & OOP                             | Access modifiers, inheritance, abstract classes, `implements`, decorators and mixins at read-only level.                                                       | 4-5 hrs    |
| **7**  | Modules, Declaration Files & Config       | ESM vs CJS, `import type`, `.d.ts`, `@types`, module augmentation (extending Express `Request`), ESLint + Prettier.                                            | 4-5 hrs    |
| **8**  | Async, Errors & Runtime Validation        | Promise typing, `unknown` in `catch`, custom errors, Result pattern, Zod for runtime validation.                                                               | 4-5 hrs    |
| **9**  | TypeScript with Node + Express            | Full backend setup, typed middleware, controllers, services, Mongoose/Prisma, JWT, error handler, testing, NestJS intro.                                       | 8-10 hrs   |
| **10** | TypeScript with React                     | Props, events, hooks, generic components, context, TanStack Query, React Hook Form + Zod, Redux Toolkit, Router.                                               | 8-10 hrs   |
| **11** | End-to-End Type Safety                    | Shared types, shared Zod schemas, typed API client, tRPC intro, one complete feature from DB to UI.                                                            | 5-6 hrs    |
| **12** | Working with Legacy Code                  | JS to TS migration, replacing `any`, `@ts-expect-error`, navigating large codebases, top 25 compiler errors with fixes, TS 4.x to 5.x differences.             | 5-6 hrs    |
| **13** | Best Practices, Interview Prep & Practice | Best practices, 50 interview questions, 10 challenges, 3 portfolio projects, one-page cheat sheet, job-ready checklist.                                        | 8-10 hrs   |

**Delivery note:** Any Part that would exceed 2,500 words (likely Parts 5, 9 and 10) will be split into Na / Nb rather than dropping topics.
